# マインスイーパー（MATLAB）

MATLAB の GUI（`uicontrol`）で作ったマインスイーパーです。
地雷の数え方が違う 2 つのバージョンがあります。

| ファイル | 内容 |
| --- | --- |
| `MineSweeper_3x3.m` | 完成版（通常ルール）。開いたマスに **周囲 8 マス（3×3）** の地雷の数を表示 |
| `MineSweeper_5x5.m` | ルール変更版。開いたマスに **自分を中心とした 5×5 の範囲（周囲 24 マス）** の地雷の数を表示 |

## 実行方法

このフォルダを MATLAB のカレントフォルダにして、コマンドウィンドウでファイル名を入力します。

```matlab
MineSweeper_3x3    % 通常ルール
MineSweeper_5x5    % 5×5 ルール
```

※ どちらのファイルも、中の関数名は元のまま `MineSweeper2_GUI` です。
MATLAB はファイル名で呼び出すので、上のようにファイル名で実行してください
（エディタに「関数名とファイル名が一致しない」という注意が出ますが、動作に問題はありません）。

## 操作方法

- **左クリック**：マスを開く
  - 地雷だった場合はゲームオーバー（全ての地雷が `M` で表示されます）
  - 地雷でなければ、周囲の地雷の数が表示されます
- **右クリック**：旗 `F` を立てる／外す
- 地雷以外のマスを全て開くとクリア

## 設定

各ファイルの先頭で変更できます。

| 変数 | 初期値 | 意味 |
| --- | --- | --- |
| `n` | 9 | 盤面のサイズ（n × n） |
| `num_mines` | 11 | 地雷の数 |

## 2 つのバージョンの違い

違いは、関数 `count_adjacent_mines` の中で数える範囲を決めている `neighbors` だけです。

**MineSweeper_3x3.m**（表示される数字は 0〜8）

```matlab
neighbors = [x-1, y-1; x-1, y; x-1, y+1;
             x, y-1;             x, y+1;
             x+1, y-1; x+1, y; x+1, y+1];
```

**MineSweeper_5x5.m**（表示される数字は 0〜24）

```matlab
neighbors = [x-2, y-2; x-2, y-1; x-2, y; x-2, y+1; x-2, y+2;
             x-1, y-2; x-1, y-1; x-1, y; x-1, y+1; x-1, y+2;
             x  , y-2; x  , y-1;         x  , y+1; x  , y+2;
             x+1, y-2; x+1, y-1; x+1, y; x+1, y+1; x+1, y+2;
             x+2, y-2; x+2, y-1; x+2, y; x+2, y+1; x+2, y+2];
```

5×5 版は 1 つの数字が広い範囲の情報を含むため、地雷の位置を絞り込むのが通常版より難しくなります。

## 補足

- 0 のマスを開いても、周りのマスは自動では開きません（1 マスずつ開きます）。
